# 🎨 Asian Paints – Sales & Performance Analytics Dashboard

## 📊 Project Overview

The **Asian Paints Sales & Performance Analytics Dashboard** is an interactive business intelligence project developed using **Microsoft Power BI Desktop**.

This project provides a comprehensive analysis of sales performance, revenue, profit, regional performance, product analytics, dealer performance, and business trends.

The dashboard helps users understand business performance through interactive visualizations, KPI cards, charts, maps, and filters.

## 🎯 Project Objectives

- Analyze overall sales and revenue performance.
- Monitor total profit and profit margins.
- Compare regional and state-wise performance.
- Analyze product and category contributions.
- Track dealer performance and order information.
- Understand monthly revenue and profit trends.
- Analyze revenue targets and forecasts.
- Create interactive business dashboards.

## 🚀 How to Use This Project

1. Download or clone this repository.
2. Open the `.pbix` file using Power BI Desktop.
3. Load the required dataset if prompted.
4. Explore all five dashboard pages.
5. Use slicers to filter and analyze the data.
6. Interact with charts to explore business performance.
